# Prohori Dashboard

Monitoring dashboard for the "Prohori" cowshed IoT sensor product (ammonia, methane, humidity, temperature).

## Project Setup

### Server
1. `cd server`
2. `cp .env.example .env` (fill in your `MONGO_URI`)
3. `npm install`
4. `npm run dev` (or `node src/app.js`)

### Client
1. `cd client`
2. `cp .env.example .env`
3. `npm install`
4. `npm run dev`
